#  Artisan Brew Coffee House

A modern, responsive coffee shop website built using **Semantic HTML5** and **Modern CSS3**. This project showcases a clean and elegant user interface for a fictional coffee house, featuring smooth navigation, responsive layouts, and visually appealing sections.

---

##  Features

- ✅ Responsive design for desktop, tablet, and mobile
- ✅ Sticky navigation bar
- ✅ Hero section with call-to-action
- ✅ About Us section
- ✅ Coffee specialties/services section
- ✅ Contact information and contact form
- ✅ Image gallery
- ✅ Modern UI with smooth scrolling
- ✅ Built using Semantic HTML5 & CSS3

---

##  Technologies Used

##  Getting Started

1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/artisan-brew-coffee-website.git
```

2. Open the project folder.

3. Open **index.html** in your web browser.

No installation or additional dependencies are required.
